# FoodExpress - Food Delivery Website

A modern, responsive food delivery website built with HTML, CSS, and JavaScript. This project showcases a beautiful UI/UX design with interactive features for ordering food online.

## 🍕 Features

### Core Features
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, intuitive interface with smooth animations
- **Interactive Cart**: Add/remove items, quantity management, and total calculation
- **Search Functionality**: Location-based restaurant search
- **Smooth Navigation**: Fixed navbar with smooth scrolling
- **Mobile Menu**: Hamburger menu for mobile devices

### Sections
1. **Hero Section**: Eye-catching landing area with call-to-action buttons
2. **Search Section**: Address input for finding nearby restaurants
3. **Categories**: Popular food categories with icons
4. **Featured Restaurants**: Restaurant cards with ratings and delivery info
5. **Menu Items**: Food items with pricing and add-to-cart functionality
6. **Features**: Service highlights (fast delivery, fresh food, etc.)
7. **Footer**: Contact information and social links

### Interactive Elements
- Shopping cart with slide-out modal
- Add to cart buttons with quantity management
- Search functionality with notifications
- Smooth scrolling navigation
- Hover effects and animations
- Mobile-responsive hamburger menu

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Installation
1. Clone or download the project files
2. Open `index.html` in your web browser
3. That's it! The website is ready to use

### File Structure
```
food-delivery/
├── index.html          # Main HTML file
├── styles.css          # CSS styles and responsive design
├── script.js           # JavaScript functionality
└── README.md           # Project documentation
```

## 🔧 Customization

### Adding New Menu Items
1. Find the menu section in `index.html`
2. Copy an existing menu item structure
3. Update the image, name, description, and price
4. The cart functionality will automatically work

### Changing Colors
1. Open `styles.css`
2. Find the CSS custom properties or color values
3. Replace with your preferred colors
4. Update the gradient values if needed

### Adding New Categories
1. Find the categories section in `index.html`
2. Copy an existing category card
3. Update the icon, title, and description
4. Choose an appropriate Font Awesome icon
